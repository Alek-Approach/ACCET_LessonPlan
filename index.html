Google Drive settings

“Save to Google Drive” needs an OAuth Client ID from your Google Cloud project. It is stored only in this browser.

  1. In Google Cloud Console, enable the Google Drive API.
  2. Create an OAuth client ID of type Web application.
  3. Add your page’s address (e.g. https://approachisc.github.io) under Authorized JavaScript origins.
  4. Paste the Client ID below.
